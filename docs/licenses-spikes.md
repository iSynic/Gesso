## Notes (written at Stage 1, before the product workspace existed; see `licenses.md`)

- Every crate below is permissive or dual-licensed with a permissive option. Entries such as
  `GPL-2.0-only` (self_cell) and `LGPL-2.1-or-later` (r-efi) appear only because those crates are
  dual/tri-licensed (`Apache-2.0 OR GPL-2.0-only`, `MIT OR Apache-2.0 OR LGPL-2.1-or-later`); we
  take the permissive option.
- **MPL-2.0** crates (`cssparser`, `cssparser-macros`, `selectors`, `dtoa-short`) come only from
  Tauri/wry's HTML stack; `option-ext` (MPL-2.0) comes from `dirs`. If the native shell is chosen,
  only `option-ext` remains (and can be avoided).
- **Skia** (`skia-bindings`, MIT) downloads prebuilt Skia binaries (BSD-3-Clause) whose static lib bundles third-party code (HarfBuzz,
  ICU, libpng and others); a product shipping Skia must add
  Skia's third-party notices. Not needed if Vello is chosen.
- **QuickJS** (via `rquickjs-sys`, MIT) — QuickJS itself is MIT.
- **Fonts**: the spikes use Windows system fonts at runtime and ship none. A product that bundles
  fonts must use OFL-1.1 or similar (already in the allowlist) and include their license texts.
- **FigCraft** (Apache-2.0 OR MIT) is not a dependency; anything borrowed from it later is copied
  with attribution under its license (see `docs/figcraft-evaluation.md`).
